# Flickbar Homebrew tap

```sh
brew install --cask flickbar/tap/flickbar
```

[Flickbar](https://github.com/flickbar/flickbar) snaps, resizes and moves macOS windows with trackpad gestures
on their title bars. Free and open source (GPL-3.0-or-later).

Flickbar isn't notarized by Apple yet, so macOS blocks it the first time you open it: open it once, then click
**Open Anyway** in *System Settings → Privacy & Security*.
